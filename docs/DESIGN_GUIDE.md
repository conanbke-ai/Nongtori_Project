# Design Guide

## 디자인 방향

농토리 UI는 농업 현장에서 빠르게 이해할 수 있는 **단순하고 명확한 상태 중심 인터페이스**를 지향합니다.

### 사용자 우선순위

1. 지금 상태가 정상인지 이상인지 바로 알 수 있을 것
2. 다음에 무엇을 해야 하는지 바로 알 수 있을 것
3. 글을 길게 읽지 않아도 주요 기능을 사용할 수 있을 것
4. 모바일 화면에서 터치하기 쉬울 것
5. 향후 외국인 작업자를 위한 다국어 확장이 쉬울 것

## 마스코트

기존 딸기 프로젝트에서 발전시킨 **정찰 토끼** 콘셉트를 유지합니다.

주요 상태:

- 농장 순찰 중
- 사진 촬영 중
- 데이터 처리 중
- 분석 중
- 이상 징후 발견
- 정상 상태
- 분석 완료
- 재촬영 안내

마스코트는 장식용으로 과도하게 사용하지 않고 상태/행동을 보조하는 역할로 사용합니다.

## 캐릭터 기준

- 하늘색 계열 토끼
- 둥근 고글/바이저
- 귀엽고 생동감 있는 표정
- 뒷발 텀핑/팡팡 모션 활용 가능
- 가방/장비가 발 동작과 겹치지 않도록 구성
- 초록 누더기형 의상 지양
- 지나치게 뚱뚱하거나 발바닥이 과장된 형태 지양

## 결과 화면 정보 구조

```text
상태
↓
핵심 결과
↓
왜 그렇게 판단했는지
↓
사용자가 바로 할 행동
↓
세부 데이터 / 분석 기록
```

예시:

```text
주의가 필요해요
응애 의심 징후가 보여요
잎 가장자리의 패턴과 온도 변화가 평소와 달라요
→ 잎 뒷면을 더 가까이 촬영해 주세요
```

## 접근성

- 색상만으로 상태를 표현하지 않습니다.
- 아이콘 + 텍스트 + 색상을 함께 사용합니다.
- 본문 글씨를 과도하게 작게 만들지 않습니다.
- 터치 버튼 간격을 충분히 확보합니다.
- 오류 메시지는 기술 용어보다 해결 행동을 우선합니다.

## 디자인 자산

`assets/design/`은 이전 딸기 프로젝트에서 생성한 콘셉트 자산을 보존하는 영역입니다.

실제 제품 UI에 적용할 때에는 해당 이미지 전체를 그대로 화면에 삽입하기보다 마스코트 포즈·색감·상태 표현의 참고 기준으로 사용합니다.
