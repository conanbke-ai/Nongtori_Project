# Project Scope

## 프로젝트 정의

농토리는 기존 딸기 프로젝트에서 출발한 **데이터 기반 스마트팜 현장 지원 서비스**입니다.

첫 적용 작물은 딸기지만, 프로젝트 목표는 딸기 전용 판별기를 만드는 것이 아니라 이미지·환경·센서 데이터를 활용해 작물 상태를 분석하고 현장 작업을 지원하는 확장 가능한 구조를 만드는 것입니다.

## 핵심 사용자

### 농민 / 농장 관리자
- 현재 작물 상태 빠른 확인
- 이상 징후 조기 발견
- 분석 기록 추적
- 재촬영/추가 확인 행동 안내

### 현장 작업자
- 복잡한 전문용어 없이 촬영/확인 절차 수행
- 큰 버튼과 명확한 상태 표시
- 향후 다국어 지원

### 포트폴리오 평가자
- 데이터 수집 → 모델/규칙 → API → UI로 이어지는 전체 파이프라인 확인
- 확장 가능한 아키텍처와 테스트 전략 확인

## 1차 기능 범위

### 작물 품질
- 딸기 숙도 분류
- 상품 등급 분류
- 외관 이상 탐지

### 병해충/이상 징후
- 흰가루병 우선 진단 흐름
- 응애 조기 예찰
- 정상/주의/이상 상태 표현
- 필요 시 재촬영 안내

### 데이터
- RGB 이미지
- IR/열화상 이미지 가능성 검토
- 온도/습도 등 환경 데이터
- 관수 전/후 조건 기록
- 농가/구역/촬영 시점 메타데이터

### 사용자 경험
- 사진 촬영 중심의 단순 흐름
- 분석 진행 상태
- 분석 결과와 권장 행동
- 기록 관리
- 이상 징후 알림

## 확장 범위

- 토마토·고추 등 작물 Strategy 추가
- 외부 기상 데이터 Adapter
- IoT 센서 Adapter
- 실시간 영상 기반 탐지
- 병해충 객체 탐지/세그멘테이션
- 농장 구역별 시계열 분석
- 수확량/생육 예측

## 제외/보류

현재 포트폴리오 단계에서는 다음을 무리하게 상용 수준으로 구현하지 않습니다.

- 실제 농장 제어 장비 자동 제어
- 농약/방제 자동 처방
- 의료·법적 수준의 확정 판정 표현
- 모든 작물 지원
- 대규모 상용 멀티테넌시

## 성공 기준

1. 사용자가 입력한 작물/환경 데이터를 안정적으로 수집한다.
2. 분석 결과와 근거/신뢰도를 일관된 계약으로 제공한다.
3. 모델/작물 변경이 UI와 DB 전체 수정으로 이어지지 않는다.
4. 실제 농업 현장에서 이해할 수 있는 결과 화면을 제공한다.
5. 데이터·모델·서비스 개발 역량을 포트폴리오에서 설명할 수 있다.
