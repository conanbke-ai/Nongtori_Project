# TORI Family Character Standard — 농토리

농토리는 TORI MASTER를 공유하는 TORI 패밀리의 형제 캐릭터다. 토끼 본체의 얼굴·귀·체형·손발·아이보리 화이트 기본 털색은 고정하고, 프로젝트 개성은 눈동자와 의상·장비·포인트 컬러·표정·모션으로 표현한다.

## 농토리 캐릭터성

- 성격: 성실함, 부지런함, 친근함, 책임감
- 눈동자: 자연을 연상시키는 맑은 그린 계열
- 포인트 컬러: 세이지·그린 중심, 당근 오렌지는 작은 강조색으로만 사용
- 의상: 귀여운 초록 모자와 가벼운 현장형 소품을 우선
- 금지: 삽·갈퀴·장화·두꺼운 작업복을 한꺼번에 사용해 '농부 캐릭터' 자체로 보이게 하는 과도한 농부 코스튬
- 모션: 작은 식물을 확인하거나 메모하고, 성실하게 돌아다니며 상태를 점검하는 행동

## 기준 자산

- 공식 프로젝트 캐릭터: `assets/nongtori-tori.webp`

현재 `Nongtori_Project` 저장소는 프로젝트 기준 문서 중심이며 실행 가능한 프론트엔드가 들어 있지 않다. 실제 UI 소스가 이 저장소에 추가되는 즉시 위 자산을 기본 mascot source of truth로 연결한다. 새 화면이나 문서에서 서로 다른 토끼를 임의로 생성하지 않는다.

## TORI 패밀리 공통 원칙

농토리의 털색을 초록색으로 바꾸지 않는다. TORI MASTER의 기본 털색을 유지하고 그린 눈동자, 초록 모자·소품, 성실한 표정과 모션으로 농토리를 구분한다. 이렇게 해야 미스토리·운토리와 나란히 놓였을 때 같은 패밀리이면서도 서로 다른 형제 캐릭터로 읽힌다.
