# 농토리 캐릭터 적용 표준

> 이 문서는 편입 전 Site의 캐릭터 적용 이력입니다. 현재 canonical 자산은 [`assets/nongtori-tori.webp`](../assets/nongtori-tori.webp)이고, 현재 프로젝트 기준과 충돌하는 아래의 외형 설명이나 이미지 생성 지침은 적용하지 않습니다. 기존 이미지 파일은 이력 보존용으로 유지하며, 이번 편입에서 로그인·대시보드 본문 이미지는 canonical 자산으로 연결했습니다. 앱 아이콘과 공유 이미지는 기존 파일을 유지했습니다.

이 문서는 농토리 운영센터에서 사용하는 캐릭터의 고정 기준입니다. 앱에는 TORi 패밀리 가운데 **농토리만** 사용합니다.

## 변경하지 않는 요소

- 흰 털의 어린 토끼 비율과 둥근 얼굴
- 초록 눈동자
- 새싹 문양이 있는 올리브색 모자
- 크림색 셔츠와 초록색 멜빵 작업복
- 황동색 금속 장식
- 갈색 크로스백과 주황색 당근 장식
- 표준 시안의 색, 재질, 형태와 전체 실루엣

고글, 딸기 모자, 다른 작업복, 다른 캐릭터의 소품처럼 표준에 없는 요소를 추가하지 않습니다. 미스토리·운토리의 외형이나 색을 농토리와 섞지 않습니다.

## 바꿀 수 있는 요소

표준 시안에 정의된 범위에서 표정과 동작만 바꿀 수 있습니다.

- 표정: 기본, 웃음, 윙크, 놀람, 집중, 응원
- 동작: 주변 살피기, 땅 확인하기, 새싹 살피기, 기록 확인하기, 다시 점검하기, 준비 완료

새 이미지를 만들 때도 아래 원본 시안을 함께 참조하고, 외형·의상·소품은 그대로 복제한 뒤 표정 또는 동작만 지정합니다.
